```jsx
<Input placeholder="Search sightings…" />
<Input numeric value="2.0" suffix="px" />
<Input value="Berlin Wall — segments" />
```

Background is `--surface-sunken` with a `--border-strong` hairline. Used for names, search, and the value half of a property row.
