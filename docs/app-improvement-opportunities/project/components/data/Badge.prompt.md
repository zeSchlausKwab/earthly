Tiny status/type/count marker. Tinted by default, `solid` for LIVE, `mono` for counts.

```jsx
<Badge tone="amber" solid>LIVE</Badge>
<Badge tone="green">Published</Badge>
<Badge tone="violet">Poly</Badge>
<Badge tone="cyan">Line</Badge>
<Badge mono>12/43</Badge>
```

Geometry type chips use `violet` (Poly) and `cyan` (Line/Point). 16px tall, 2px radius.
