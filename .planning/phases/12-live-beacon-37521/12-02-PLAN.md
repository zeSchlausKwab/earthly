<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay (untrusted) → useBeacons read path | A relay can serve a forged/legacy/expired 37521. The client never trusts it: filter-before-cast + dropExpired at the subscription. |
| client publish → relay | The lifecycle service is the only writer; it controls which tags (t:'live'/geo) leave the device per the D-10 visibility choice. |
| device clock → staleness/expiry | created_at / expiration are device-set epoch seconds; the staleness/expiry derivation compares them against the read-side `now` in seconds. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-FORGED | DoS (tab freeze) | useBeacons casting a forged/legacy 37521 | mitigate | `events.filter(isLiveBeacon)` BEFORE castEvent (modelVersion gate); the cast ctor throws on a non-conforming event, so the filter is the SPEC-03 defensive skip (P-2). |
| T-12-02-EXPIRED | Information disclosure | Relay serving an expired beacon | mitigate | `dropExpired(.., now)` at the useBeacons subscription read path; relay GC is lazy/untrusted (SPEC-05). The 15s tick re-derives so an expired beacon disappears without a new event. |
| T-12-02-FROZEN | Spoofing / integrity | A stopped/stale beacon shown as current | mitigate | beaconState treats `now - created_at >= threshold` as STALE regardless of `status` (P-3); a failed ended-publish still degrades honestly to stale, never frozen-as-live. |
| T-12-02-LINKONLY | Information disclosure | Link-only beacon leaking discovery tags | mitigate | The lifecycle service omits `t:'live'` AND `g`/`bbox` for link-only (D-10/P-6); the discovery filter is `#t:['live']`, so a link-only beacon is never matched. |
| T-12-02-CLOCK | Tampering | Staleness/expiry computed in ms not epoch seconds | mitigate | beaconState + useBeacons use epoch-seconds (`unixNow()`/passed `now`) only; the only ms value in the whole subsystem is the setInterval tick (P-1). |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | No package installs; @turf/turf, applesauce-core, geojson are pre-existing deps (12-RESEARCH § Package Legitimacy Audit: zero new deps). |
</threat_model>
