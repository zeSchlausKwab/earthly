<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device GPS → publish loop | navigator.geolocation fixes drive the publish loop; foreground-only (watchPosition is browser-suspended when backgrounded). |
| session key (secret) → memory only | The throwaway secp256k1 key is the session secret; it lives in a React ref and NEVER touches a datastore. |
| publish loop → relay | The loop is rate-limited by the distance+time floor; a jittery GPS or a coincident fix+interval cannot flood the relay. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-03-KEYLEAK | Information disclosure | Throwaway session key persisted/leaked | mitigate | The `sk` is held in a React ref only; NEVER localStorage/IndexedDB; discarded at Stop. A new Start mints a fresh key (sessions unlinkable). Test asserts no storage write (D-05). |
| T-12-03-DEANON | Information disclosure | De-anonymization via own-pubkey publish | mitigate | Anonymous throwaway key is the DEFAULT; my-account is an explicit opt-in branch (the banner/consent in Plan 05 weights it stronger) (D-05/D-06). |
| T-12-03-FLOOD | DoS (self-DoS the relay) | Heartbeat flood / jittery-GPS double-publish | mitigate | Single `lastPublished` guard shared by the fix path + the heartbeat interval; distance+time floor caps the rate (P-4). |
| T-12-03-FROZEN | Spoofing / integrity | Fix-unavailable mid-session frozen as live | mitigate | On POSITION_UNAVAILABLE/TIMEOUT the loop does NOT republish a stale point — it lets staleness take over honestly (the marker greys out because no fresh created_at arrives); the banner shows a searching sub-state (P-3). |
| T-12-03-STOPFAIL | Integrity | Stop publish fails → last point stays "live" | mitigate | stopBeacon retries/confirms the ended publish and surfaces an error; the marker treats past-threshold as STALE regardless of status so a failed ended-publish still degrades honestly (P-3). |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | No installs; applesauce-signers + nostr-tools are pre-existing (12-RESEARCH § Package Legitimacy Audit: zero new deps). |
</threat_model>
