<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay → client read (useSightings) | Arbitrary Nostr authors publish 37522 events; untrusted content/geometry/expiration cross into the cast + timeline. |
| relay → client (expiry freshness) | A lagging/malicious relay may serve an expired Sighting (NIP-40 GC is advisory). |
| localStorage → client (draft) | Per-device, pubkey-scoped; no cross-user trust boundary, but a malformed stored value must not crash. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Denial of Service | useSightings casting a legacy/forged/missing-modelVersion 37522 | mitigate | `events.filter(isTemporalSighting)` BEFORE `castEvent` (cast ctor throws by design — SPEC-03 defensive skip); one bad event cannot blank the timeline (Pitfall P-2). |
| T-11-02-02 | Tampering/Spoofing of freshness | Relay serves an expired Sighting at the subscription read path | mitigate | `dropExpired(events, unixNow())` in the useMemo — UTC epoch seconds, never `Date.now()` ms; never trust relay GC (SIGHT-03 / Pitfall P-1). |
| T-11-02-03 | Denial of Service | Oversized/malformed `geometry` in untrusted content fed to turf bbox/centroid | mitigate | turf calls wrapped in try/catch returning undefined (mirror computeBboxFor/computeGeohashFor); D-02 area is "small" by design; derivation failure degrades to no bbox/g, never throws. |
| T-11-02-04 | Tampering | Malformed draft value in localStorage | accept | `readDraftMap` returns `{}` on any non-object/array value and never throws (cloned defensive read); local-only, pubkey-scoped — no trust boundary crosses (mirrors Story T-10-03). |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | Zero new deps; all libraries (`@turf/turf`, `geojson`, `applesauce-core`) already in the tree (RESEARCH § Package Legitimacy Audit: not applicable). |
