# Phase 11 — UI Design Contract

> Visual and interaction contract for Temporal Sighting (kind 37522) authoring + reading UX. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Inheritance posture:** Earthly is an EXISTING app with a locked design system. This phase MIRRORS the Phase-10 Story spine (browse rail → info-panel view/editor → deep-link + OG card) almost 1:1 and reuses existing map-layer styling. It does NOT introduce a new design language. All spacing/typography/color below are declared BY REFERENCE to the established `styles/globals.css` tokens and the Phase-9/10 panel components, not invented. The only net-new visual surfaces are: (1) the map-first pin-drop create affordance + compact create form, (2) the distinct Sighting marker with observation-state time cue + expiry fade, and (3) the NIP-40 expiry preset picker. Those three are specified concretely.

## Spacing Scale

Earthly's Tailwind v4 base unit is `--spacing: 0.25rem` (4px), so the standard 4-point scale applies. Declared values (all multiples of 4):

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `gap-1` / `p-1` | Icon-to-label gaps, badge inner padding, time-cue chip padding |
| sm | 8px | `gap-2` / `p-2` | Compact form-field spacing, marker label offset, browse-row inner gaps |
| md | 12px | `gap-3` / `p-3` | Panel surface padding (matches `EntityPanelSurface` `px-3 py-3`), section spacing (`space-y-3`) |
| lg | 16px | `gap-4` / `p-4` | Editor form section spacing (`space-y-4`), card content padding |
| xl | 24px | `gap-6` | Major section breaks within a panel |
| 2xl | 32px | `gap-8` | Empty-state vertical centering |

Exceptions:
- **Panel surface padding is 12px (`px-3 py-3`)**, matching the existing `EntityPanelShell` discussion/surface tone — do NOT use 16px here, it would break visual continuity with Story/Group panels.
- **Map marker hit target ≥ 44px** — the Sighting marker's clickable area must be ≥44px square for touch (mobile-first per CLAUDE.md), even though the visible glyph is smaller. This is a touch-target floor, achieved via an invisible padded layer, not a literal 44px glyph.

## Typography

Earthly uses Poppins via the shadcn type ramp; sizes are referenced by Tailwind classes (rem-based) rather than hard pixels, but the declared roles below pin exact sizes. **3 sizes + 1 reserved meta size, 2 weights.**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Heading | 20px (`text-xl`) | semibold (600) | 1.2 | Sighting title in view panel; editor panel title input rendered value |
| Body | 16px (`text-base`) | regular (400) | 1.5 | Sighting description, form input text, browse-row title |
| Label / meta | 14px (`text-sm`) | regular (400) / semibold (600) for field labels | 1.5 | Field labels, observation-time range, browse-row summary, author/date meta |
| Caption / cue | 12px (`text-xs`) | semibold (600) | 1.4 | Map time-cue chip ("LIVE" / "Upcoming" / date), expiry countdown, Badge text, Draft chip |

Weights: **regular (400)** for body/meta text, **semibold (600)** for headings, field labels, badges, and the map time-cue. No other weights. (Matches the tour/global CSS convention: 600 for titles, 400/500 for body.)

## Color

Earthly's tokens (oklch, `styles/globals.css`). The 60/30/10 split maps to existing semantic tokens — do NOT introduce new hex values.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / `--card` (white in light, near-black in dark) + `--panel-bg` (`oklch(1 0 0 / 80%)` translucent) | Map canvas, info-panel surfaces, browse-panel background, form fields |
| Secondary (30%) | `--sidebar` / `--muted` / `--secondary` (blue `oklch(0.748 0.155 233)`) | Left rail, card/row backgrounds, subordinate chips, "upcoming" cue tint |
| Accent (10%) | `--primary` (warm amber/gold `oklch(0.854 0.174 89)`) | RESERVED — see list below |
| Destructive | `--destructive` (red `oklch(0.583 0.239 28)`) | Delete Sighting only |

**Accent (`--primary`) reserved exclusively for:**
1. The **"New Sighting"** primary button (top of the Sightings browse panel + the rail New action).
2. The **"Publish Sighting" / "Save changes"** submit button in the editor panel.
3. The **"live now" map marker highlight** — the one observation state that should pop (D-06). A Sighting currently within its `start`–`end` window renders with a `--primary` ring/glow. Upcoming and past states do NOT use accent.
4. The selected-state ring on the chosen **expiry preset** and the active **Group-attach** chip.

Accent is NEVER used for: ordinary links, all interactive elements generally, the "adjust time" toggle, non-live markers, comment actions, or section headers.

**Observation-state color encoding (D-06 — net-new, subtle):**
| State | Definition | Marker treatment | Cue chip |
|-------|-----------|------------------|----------|
| Live now | `now` within `[start, end]` (or `start ≤ now` and no `end`, within a freshness window) | `--primary` ring/glow, full opacity | "LIVE" pill, `--primary` bg, 12px semibold |
| Upcoming | `start > now` | `--secondary` (blue) outline, full opacity | "Upcoming" pill, `--secondary` tint |
| Past | `end < now` (or `start < now` past freshness) | neutral fill (`--muted-foreground`), full opacity | relative date ("3d ago"), `--muted-foreground` |
| Aging (nice-to-have, D-05) | approaching NIP-40 `expiration` | opacity ramp toward 0 as `now → expiration` (e.g. linear 1.0→0.35 over final quartile) | — |

Hard expiry (`isExpired`) = marker REMOVED entirely by `dropExpired` at every read path. The opacity aging is the optional cheap-if-available nice-to-have; removal is required.

## Copywriting Contract

All user-facing strings rendered as escaped React text nodes (no `dangerouslySetInnerHTML`) — consistent with Story/Group XSS posture.

| Element | Copy |
|---------|------|
| Primary CTA (browse + rail) | **New Sighting** |
| Create-flow placement prompt (cursor armed) | "Click the map to drop your sighting" (map overlay hint while pin-drop is armed) |
| Editor submit (create) | **Publish Sighting** |
| Editor submit (edit) | **Save changes** |
| Title field placeholder | "What did you see?" |
| Description field placeholder | "Add details — what, where exactly, anything notable…" |
| Observation-time collapsed default label | "Observed now" (with a subtle **Adjust time** text affordance — D-03) |
| Observation-time expanded labels | "Observed" (`start`) · "Until (optional)" (`end`) |
| Expiry picker label | "Fade from map" |
| Expiry preset options | "After 1 day" · "After 1 week" · "After 1 month" · "Never" · "Custom date…" |
| Expiry default | **After 1 month** (conservative — a fresh observation does not auto-vanish; Open-Question Q-1 resolved to 1 month, NOT coupled to observation `end`, D-04 / Pitfall P-4) |
| Group attach label | "Add to a Group (optional)" — reuses `GroupAttachField` |
| Group schema warn (advisory, never blocks) | reuse Phase-9 amber `Alert variant="default"` copy: "This Group expects a specific shape. You can publish anyway." |
| Empty state heading (no sightings) | "No sightings yet" |
| Empty state body (no sightings) | "Spotted something? Drop your first sighting on the map." (with the **New Sighting** button beneath) |
| Empty state (search no match) | "No sightings match" |
| View panel: no selection | "No sighting selected" |
| Expiry countdown (view panel) | "Fades in 6 days" / "Fades soon" (< 24h) / no countdown when "Never" |
| Error: publish failed | "Couldn't publish your sighting. Check your connection and try again." |
| Error: sighting not found (deep link) | "This sighting isn't available — it may have expired or been removed." |
| Draft chip (browse row) | "Draft" Badge (`variant="secondary"`) — local-first draft, mirrors Story draft |
| Destructive confirmation | **Delete sighting**: "Delete this sighting? This removes it from the map and can't be undone." — `AlertDialog`, destructive-toned confirm, owner-only |

**Three-timestamp legibility rule (Pitfall P-3):** the form NEVER shows `created_at`, `start`/`end`, and `expiration` as three equal-weight raw epoch inputs. Hierarchy: observation time collapses to "Observed now" by default (one tap); expiry is a friendly preset, not a raw date; `created_at` is never user-editable.

## Net-New Surface Specs (concrete — these have no Phase-10 twin)

### 1. Map-first pin-drop create affordance (D-01)
- Trigger: **New Sighting** (browse panel top OR rail New action) arms GeoEditor `DrawPointMode`; cursor becomes a crosshair/pin; a dismissible map overlay hint shows "Click the map to drop your sighting".
- On click: point placed, the **SightingEditorPanel** opens in the right info panel (clone of `StoryEditorPanel` layout). Map remains the canvas; the form is compact (single column, `space-y-4`).
- Optional area (D-02): an **"Draw an area instead"** secondary text affordance switches GeoEditor to line/polygon draw; the resulting geometry replaces the point. Keep it visually subordinate (not accent).
- Cancel placement: `Esc` or an overlay "Cancel" button returns to idle without opening the form.

### 2. Distinct Sighting marker + time cue + fade (D-05/D-06)
- Marker must read as an **ephemeral observation**, visually distinct from dataset dots and story pins. Recommended: an eye/sighting glyph (lucide `Eye` or `Telescope` motif) in a pill/teardrop, NOT a plain circle.
- Time-cue and opacity encoding per the Observation-state table above. Cue is **subtle** — a small chip/ring, reuse existing map-layer paint expressions (data-driven on `start`/`end`/`now`).
- Touch target ≥ 44px (see Spacing exceptions).
- Expired markers are removed by `dropExpired`, never merely hidden.

### 3. NIP-40 expiry preset picker (D-04)
- A `RadioGroup` (or segmented `Select`) of 5 presets: 1 day / 1 week / 1 month / Never / Custom date. Default **1 month**, visibly pre-selected.
- "Custom date…" reveals a `calendar` popover (the existing `@/components/ui/calendar` primitive — confirmed present; no new dep, no native `datetime-local`).
- Selected preset carries the accent ring (reserved-accent item #4). Expiry is independent of observation `end`.
