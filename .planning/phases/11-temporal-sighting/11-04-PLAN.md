<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay → detail view | Untrusted 37522 title/description rendered in SightingViewPanel; comment content via the sanitized comment renderer. |
| crawler → OG server fetch | An arbitrary `/sighting/:naddr` crawl triggers a raw-WebSocket relay fetch on the OG renderer (separate read path, no cast/filter). |
| relay → OG freshness | The OG fetch may receive an expired/removed sighting from a lagging relay and leak it via the social card. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04-01 | Information Disclosure | OG social card leaking an EXPIRED sighting (SIGHT-03 partial) | mitigate | `fetchSightingOGData` reads the `expiration` tag and returns null when past (`isExpired`/epoch-seconds) — the OG fetch is its own read path; expired sightings are never rendered into the card (Pitfall P-1). |
| T-11-04-02 | Tampering (XSS) | SightingViewPanel + OG template rendering title/description | mitigate | View renders escaped React text nodes (no `dangerouslySetInnerHTML`); OG html reuses the audited `generateOGHtml` escaping (T-10-09). |
| T-11-04-03 | Denial of Service / Resource exhaustion | OG renderer fetching an arbitrary event id (SSRF/exhaustion) | mitigate | Reuse the existing OG cache + `fetchEvent` raw-WS path (same bounded fetch as story/context, already shipped); naddr decode validates the kind (`!== TEMPORAL_SIGHTING_KIND` → null) so non-sighting ids are rejected before render. |
| T-11-04-04 | Denial of Service | Casting a legacy/forged 37522 in the detail/route resolve | mitigate | The route resolve finds the sighting via `useSightings()` which already filter-before-casts + dropExpires; the view-panel render is gated on `isExpired`. |
| T-11-04-SC | Tampering | npm/pip/cargo installs | accept | Zero new deps; OG/route/comment surfaces reuse shipped modules (RESEARCH § Package Legitimacy Audit: not applicable). |
