<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| relay → map/browse render | Untrusted 37522 title/description/geometry/start/end/expiration rendered in the marker layer + browse rows + form. |
| relay → expiry freshness | Map source + browse panel are independent read paths; a lagging relay may serve expired sightings. |
| contributor → schema Group (c-attach) | Off-thread schema validation of the attach against a potentially malicious relay-authored schema. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Tampering (XSS) | SightingsPanel rows + SightingEditorPanel rendering title/description | mitigate | Render as escaped React text nodes (clone Story row pattern — T-10-05); NO `dangerouslySetInnerHTML`. |
| T-11-03-02 | Tampering/Spoofing of freshness | Map marker source enumeration (a SEPARATE read path from useSightings) | mitigate | `dropExpired(events, unixNow())` BEFORE building the source FeatureCollection; expired markers removed, not hidden (Pitfall P-1). |
| T-11-03-03 | Denial of Service | Off-thread schema validation during c-attach to a malicious `schema` Group (ReDoS/recursive) | mitigate | Reuse `GroupAttachField` → Phase-8 off-thread hardened worker (timeout-kill, restricted dialect); never the in-thread validator; attach is warn-not-block, never a worker-DoS publish gate (SIGHT-02 / GROUP-04). |
| T-11-03-04 | Denial of Service | Oversized/malformed geometry rendered to the map | mitigate | geometry parse via the Plan-02 try/catch-guarded derivation; D-02 area is small by design; a feature that fails to build is skipped, never crashes the layer. |
| T-11-03-SC | Tampering | npm/pip/cargo installs | accept | Zero new deps; all primitives (`calendar`, `radio-group`, lucide `Eye`) already installed (UI-SPEC Registry Safety: no new block enters the contract). |
</threat_model>
