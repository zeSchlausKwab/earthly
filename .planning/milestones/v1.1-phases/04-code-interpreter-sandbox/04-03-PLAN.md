## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Denial of Service | unbounded run_code output flooding the transcript render | mitigate | The output is already capped upstream (Plan 01 `outputCapture`, D-14); `CodeRunDisclosure` renders the capped `consoleLines` + truncation marker, and is collapsed-by-default so a large output does not auto-expand the transcript (Task 1, D-09). |
| T-04-14 | Tampering | full error stack leaking to the user / confusing the transcript | accept | Low risk — the concise user one-liner reuses the audited red `ToolError` bubble (D-11); the full error intentionally goes only to the model (Plan 02). No new error channel introduced. |
| T-04-15 | Information Disclosure | rendering raw return value that echoes sensitive computed data | accept | The return value is the script's own computed result (e.g. the route + costs); the sandbox has no path to secrets (Plan 01 confinement), so the return value cannot carry signer/wallet data. Rendered JSON-only, no HTML injection. |
