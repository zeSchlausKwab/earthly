## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → read snapshot | Only a `structuredClone`d plain-data view of ingest rows + current features crosses into the boundary; never the live editor or the ingest `Map`. |
| boundary → host (recorded calls) | The boundary returns serializable `{op,args}` records; the host replays them through `createAuthoring` on the main thread. |
| `run_code` handler → model | Runtime/timeout errors return as a structured `ToolError` (full message to model, concise to user). |
