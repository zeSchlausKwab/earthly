<objective>
Establish the FIRST test suite in this repository (zero-test baseline per TESTING.md). Build the two pieces of test infrastructure every behavior-preservation and primitive test in this phase depends on: (1) a headless GeoEditor harness backed by a mock MapLibre map so `GeoEditor` can be instantiated in `bun:test` with no DOM/WebGL, and (2) shared GeoJSON fixtures.

This is Wave 0 of a Nyquist-validated phase: the golden/characterization tests are the binding acceptance gate for Success Criterion #2 ("identical map results"), and they cannot exist without this harness. Research flags the harness as first-of-its-kind — allow spike time.

Purpose: Unblock the binding behavior-preservation golden tests (Plan 03), the read-mirror integrity test (Plan 03), the boundary tests (Plan 02), and the primitive tests (Plan 05). No production behavior changes here.
Output: A reusable `createHeadlessEditor()` + `createMockMap()` and `src/lib/test-fixtures/geo.ts`, each self-verified by a smoke test.
</objective>
