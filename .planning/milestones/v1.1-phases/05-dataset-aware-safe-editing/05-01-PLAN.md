<objective>
Complete the Phase-2-deferred modify/delete surface on the Authoring facade and build the pure add/modify/delete diff classifier — the host-side mechanism every later Phase 5 plan consumes.

Purpose: SAFE-02 requires every AI map operation to be classified add / modify / delete by diffing the proposed change against the bound dataset's current features by id. SAFE-03's preview, SAFE-04's gating, and SAFE-06's undo all sit on top of this classification. The facade today exposes only add/write/circle/buffer (all intent:'add'); modify/delete were explicitly deferred in Phase 2 (02-03). This plan lands them, routes them through the interceptor classification hook, and tightens the A3 boundary so the new verbs cannot be bypassed.

Output: `diff.ts` (pure `classifyMutation`), `modifyFeature`/`deleteFeatures` on `createAuthoring`, a classify/intent-tag interceptor in `interceptor.ts`, and a tightened `boundary.test.ts` (A3 over all four verbs + new geometry-only surface assertion).

This is an `api/`-only plan: it imports NOTHING from chat, the tool registry, or Nostr (the boundary test enforces it). The async confirm gate and UI live in later plans (04, 05).
</objective>
