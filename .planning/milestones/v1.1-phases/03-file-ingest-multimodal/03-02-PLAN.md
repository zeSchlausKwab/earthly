<objective>
Build the host-side ingest worker client: dispatch parse requests to `ingest.worker.ts` and return rows + schema, with the proven sync-fallback + timeout + broken-worker latch machinery from the existing GeoJSON worker client. This is the off-thread guarantee for INGEST-02 ("large files do not freeze the app").

Purpose: The worker (Plan 01) does the parse; this client owns the no-freeze contract — lazy worker creation, per-request id-keyed promises, a 30s timeout, and a `workerBroken` latch that sync-parses all pending on `onerror`. Reusing the in-repo pattern (RESEARCH discretion call: Worker over main-thread-chunked) means zero new bundler config.

Output: `ingestClient.ts` (`parseFileInWorker`, `terminateIngestWorker`) + its RPC/fallback/timeout test.
</objective>
