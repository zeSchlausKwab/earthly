| Boundary | Description |
|----------|-------------|
| AI model → tool args | batch/dedup/style receive untrusted predicates, ops, id→value maps, and style bags; all validated (predicate shape, normalizeStyleOptions, id existence, cap). |

| model's compacted view → full dataset | "fix all"/"recolor all" must operate over editor.getAllFeatures(), never the ~6-id sample (SAFE-05). |
