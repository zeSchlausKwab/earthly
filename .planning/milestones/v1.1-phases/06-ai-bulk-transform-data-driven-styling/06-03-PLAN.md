    - `findDuplicateGroups(features, { by:'geometry' })`: features with structurally-equal geometry form a group; survivor = first in input order (keep-first); group reports `{ survivorId, duplicateIds }` (the duplicateIds are the ones a tool will delete). A unique feature forms no group.
    - `by:'attributes'` with `keys: ['name','country']`: features with an equal tuple over those property keys group together.
    - `by:'both'`: geometry AND the attribute tuple must match.
    - No duplicates → empty group list.
    - `validateGeometryFeatures(features)`: self-intersecting polygon → `withSelfIntersections` incremented and an issue recorded (`turf.kinks(feature).features.length > 0`); near-zero-area polygon → `withZeroArea` (`turf.area(feature)` below a documented small threshold); too-few-points / unclosed ring → `invalidRings`; clean feature → no issue. Returns `{ checked, withSelfIntersections, withZeroArea, invalidRings, issues: [{ featureId, issues: string[] }] }`. Non-polygon geometry (points/lines) is checked for the applicable checks only and never throws. NO mutation, NO editor reference (read-only — TOOLS-04 contract).
