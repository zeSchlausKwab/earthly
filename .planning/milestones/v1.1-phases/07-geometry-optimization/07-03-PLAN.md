<objective>
Build the geometry-optimization core: a pure `optimize(featureCollection, targetBytes?)`
that COMPOSES existing pure turf/leaf helpers into the fixed pipeline (stitch microgaps →
lossless identical-props merge → binary-search simplify to budget), the off-thread worker
shell, and the no-freeze RPC client. This is the heart of GEO-01/02/03 — and it writes
almost NO new geometry math; it orchestrates the helpers `SimplifyManager`/`CombineManager`/
`LineOperationsManager` already use, minus the editor binding (and minus the lossy-merge bug).

Purpose: deliver an off-thread, topology-safe, property-preserving byte-budget converger
that turns the 07-01 RED tests green.
Output: `types.ts`, `optimize.ts`, `optimize.worker.ts`, `optimizeClient.ts`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main thread → worker | Host posts plain GeoJSON + a number (structured-clone); the worker is a pure compute step. |
| worker → bundle | The worker's import graph must stay secret-free (no Nostr/signer/wallet/createAuthoring). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07 | Denial of Service | binary-search loop / pathological collection | mitigate | `MAX_ITERS≈12` hard cap (D-03); the loop is weakly monotonic so it terminates; runs OFF the main thread so the UI never freezes; the RPC client's 30s timeout + sync fallback (Task 1) guarantees the promise always settles even on a stuck worker. |
| T-07-08 | Information Disclosure | secret leakage into the worker bundle | mitigate | `optimize.ts`/`optimize.worker.ts` import ONLY leaf modules (`@turf/turf`, `featureHelpers`, `geometry`, `geometryValidation`, `constants`) — never the `@/features/geo-editor/api` barrel that drags `createAuthoring → GeoEditor → Nostr → pino`. Enforced by the no-barrel grep acceptance criterion + the existing worker-bundle boundary. |
| T-07-09 | Tampering | worker error swallowing | mitigate | The worker NEVER throws out of `onmessage` (always posts `{ success:false, error }`); the client rejects/settles deterministically — no silent corrupt-result path. Budget-unreachable returns an HONEST `reachedBudget:false` report (no silent truncation, Phase 3/6 discipline). |
| T-07-10 | Denial of Service | byte re-serialization cost per iteration | accept | Full `TextEncoder` serialization per step is bounded by `MAX_ITERS` and runs off-thread (RESEARCH Pitfall 2); the incremental-delta optimization is held in reserve and only adopted if the fixture profiles slow. |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs — `@turf/turf@^7.3.5` already present (RESEARCH §"Installation: None", §"Package Legitimacy Audit: Not applicable"). slopcheck N/A. |
